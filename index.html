Advanced Method — Paste GraphQL Response

  1. Go to your Sonlight curriculum page
  2. Open browser DevTools — press F12 or right-click → Inspect
  3. Click the Network tab, then refresh the page
  4. Type graphql in the filter box to find the request
  5. Click the request, go to Response tab, copy everything
