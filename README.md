# Sonlight Book Finder

A simple tool to compare Sonlight curriculum book prices against Half Price Books and ThriftBooks.

## Features

- Import book lists from Sonlight curriculum pages
- Track prices from HPB and ThriftBooks
- See savings at a glance
- Export comparisons to CSV
- All data stored locally in your browser

## Usage

1. Visit your Sonlight curriculum page
2. Open DevTools (F12) → Network tab → filter by "graphql"
3. Copy the response JSON
4. Paste into the app and import
